OpenClaw

Política de Privacidad — Última actualización: 10 de febrero de 2026

📝 Resumen

OpenClaw no recopila, almacena, transmite ni comparte ningún dato personal. Todo se ejecuta localmente en tu dispositivo.

📖 1. Introducción

OpenClaw ("la Aplicación") es una aplicación Android de código abierto desarrollada por desarrollo032. La Aplicación configura un entorno local de puerta de enlace de IA en tu dispositivo Android usando proot y proporciona una interfaz nativa para administrarlo. Esta política de privacidad explica cómo la Aplicación maneja tus datos.

🚫 2. Recopilación de Datos

No recopilamos ningún dato. Específicamente, la Aplicación no recopila:

  • Información personal — nombre, correo electrónico, número de teléfono, etc.
  • Identificadores del dispositivo — ID de publicidad, IMEI, etc.
  • Datos de ubicación
  • Analíticas de uso o telemetría
  • Reportes de fallos
  • Historial de navegación
  • Contactos, fotos o multimedia

💾 3. Almacenamiento Local de Datos

La Aplicación almacena los siguientes datos solo localmente en tu dispositivo:

  • Rootfs de Ubuntu — Entorno Linux descargado de los servidores oficiales de Ubuntu
  • Node.js — Descargado de los servidores oficiales de Node.js
  • Preferencias de la app — Ajustes mediante Android SharedPreferences
  • URL del token del gateway — Token de autenticación local para el panel del gateway de IA
  • Claves API — Almacenadas localmente dentro del entorno proot de Ubuntu

Ninguno de estos datos se transmite a nosotros ni a terceros.

🌐 4. Uso de Red

La Aplicación usa el permiso INTERNET únicamente para los siguientes fines:

  • Configuración inicial — Descargar rootfs de Ubuntu y binarios de Node.js desde servidores oficiales
  • Gateway local — Comunicación con el gateway de IA en localhost (127.0.0.1:18789)
  • Llamadas a APIs de IA — Se conecta a las APIs de los proveedores de IA usando las claves que proporcionas

La Aplicación no se conecta a ningún servicio de analíticas, seguimiento o publicidad.

🔗 5. Servicios de Terceros

La Aplicación no integra SDKs de terceros, analíticas ni frameworks publicitarios. Al usar el gateway de IA, tu dispositivo se comunica directamente con los proveedores de IA cuyas claves API configures:

  • Google Gemini — Términos de Google AI
  • OpenAI — Política de Privacidad de OpenAI
  • Anthropic — Política de Privacidad de Anthropic

🔐 6. Permisos

Todos los permisos solicitados se utilizan únicamente para funcionalidad local:

  • INTERNET — Descargar archivos de configuración y ejecutar el gateway local
  • FOREGROUND_SERVICE — Mantener el gateway funcionando en segundo plano
  • POST_NOTIFICATIONS — Mostrar progreso de configuración y estado del gateway
  • WAKE_LOCK — Evitar que la CPU entre en reposo durante la configuración
  • REQUEST_IGNORE_BATTERY_OPTIMIZATIONS — Operación ininterrumpida del gateway

👶 7. Privacidad Infantil

La Aplicación no está dirigida a menores de 13 años. No recopilamos información de nadie, incluyendo niños, de forma consciente.

📂 8. Código Abierto

OpenClaw es completamente de código abierto bajo la Licencia MIT. Puedes inspeccionar el código fuente completo para verificar nuestras prácticas de privacidad en: github.com/desarrollo032/openclaw-termux

🔄 9. Cambios a Esta Política

Si actualizamos esta política de privacidad, los cambios se publicarán en esta página con una fecha de "Última actualización" actualizada. Como la Aplicación no recopila datos, es poco probable que haya cambios significativos.
